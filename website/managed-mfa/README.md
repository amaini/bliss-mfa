# Bliss Secure MFA marketing page

Historical draft. Use `../windows-mfa/index.html` and its `PUBLISHING.md` for
the current Windows/RDP prototype. This earlier draft's plans and managed/VPN
claims are not the current release scope.

This folder contains the WordPress-ready source for the future
`blissitek.ca/managed-mfa` product page.

The markup is deliberately framework-free so it can be:

1. placed in a WordPress Custom HTML block,
2. converted into Gutenberg blocks,
3. adapted into the current Bliss theme, or
4. used as the copy/layout reference for a page builder.

Before production publishing we still need:

- final monthly/setup pricing,
- final Bliss brand assets/logo,
- production Stripe Checkout URL/API integration,
- legal/service terms review,
- WordPress deployment access.
