Before you get started.

What do I need to install it?

A Windows machine with administrator access, an authenticator app, and a tested recovery account. The prototype has been exercised on Windows 10 Pro; broader Windows compatibility and the new clean-install package still need acceptance testing.

Where is my information stored?

Your appliance manages Windows users and authenticator enrollment locally. The hosted account portal manages subscriptions, licensing, and downloads. Windows passwords and enrollment keys are not collected by this page.

Does this use the WooCommerce checkout?

Bliss MFA uses a separate client account portal and Stripe subscription checkout. Your existing WooCommerce store remains available for its other products.

Can I deploy it to my whole team today?

This is a prototype preview. Public payment-to-activation, clean installation, and additional RDP acceptance checks must pass before general client rollout.
